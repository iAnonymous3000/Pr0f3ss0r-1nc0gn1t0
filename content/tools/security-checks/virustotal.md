VirusTotal is a fast way to triage suspicious files, links, domains, and IP addresses before deeper investigation. Key features include:
- Multi-engine scanning for files, URLs, domains, and IPs
- Helpful first-pass reputation and detection context
- Related indicators and community analysis for investigation workflows
- Useful for checking suspicious downloads or websites quickly
- Not a replacement for isolated malware analysis or sandboxing

Public VirusTotal submissions are not private. Reports are shared with the community, and submitted files or page contents may be available to security partners and premium customers. Do not submit confidential documents, personal data, or URLs containing access tokens or private sharing links. For a file, look up its hash first to check for an existing report without uploading its contents; a missing report or a clean result does not prove a file is safe.

See [VirusTotal's explanation of how submissions are shared](https://docs.virustotal.com/docs/how-it-works).
