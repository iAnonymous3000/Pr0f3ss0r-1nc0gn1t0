Authier is an early-stage open-source password manager and TOTP vault for the web and browser extensions. Key features include:

- Client-side AES-256-GCM encryption before vault data is synchronized
- Built-in TOTP code storage and generation
- Browser autofill
- Trusted-device approval
- Public source code under AGPL-3.0-or-later

Authier has not undergone an independent security audit. For important secrets, an established and independently audited password manager remains the safer choice.
