I'm **Sooraj Sathyanarayanan**, a **Program Manager at Brave** and a cybersecurity and privacy researcher. I hold an **MS in Cybersecurity from Northeastern University**.

I examine how software handles people's data, build tools for inspecting security and privacy behavior, and turn technical findings into practical guidance. My public work includes browser tooling, local forensic analysis, accepted open-source contributions and coauthored research.

## Work and research

I joined Brave in December 2025. My work there includes tooling for reviewing Brave Nightly changes. My broader background spans security and privacy assessment, penetration testing, digital forensics, infrastructure hardening, and open-source work.

My coauthored publications cover **security in edge computing** and **context-aware blockchain validation**. Read the [publications and publisher records]({{< relref "/research/_index.md" >}}#publications), or visit my [Google Scholar profile](https://scholar.google.com/citations?user=NwIwfYkAAAAJ).

My research on the privacy of fitness wearables received grant support from the [Ludlow Institute](https://www.ludlowinstitute.org/grants) through Timechain Consulting, beginning in 2025.

## Selected work

- **[Brave Nightly Change Tracker]({{< relref "/projects/_index.md" >}}#brave-nightly-change-tracker):** tooling for reviewing merged pull requests and identifying changes relevant to Brave Nightly.
- **[Site Behavior Lab]({{< relref "/projects/_index.md" >}}#site-behavior-lab):** automated browser visits that produce inspectable records of network activity, storage and consent behavior, with the conditions and limits of each observation.
- **[Trace]({{< relref "/projects/_index.md" >}}#trace):** a Rust and WebAssembly tool for examining iPhone diagnostic archives against known spyware indicators. It supports initial triage within a defined detection scope.
- **[Ente PrivacyPack contributions]({{< relref "/projects/_index.md" >}}#ente-privacypack-contributions):** accepted changes to the mobile interface, privacy-alternative selection, response headers, runtime dependencies and validation checks.
- **[SimpleX release verification]({{< relref "/projects/_index.md" >}}#simplex-server-release-v631):** independently reproduced the v6.3.1 server build, acknowledged in the official release with a published checksum signature.

The [Projects page]({{< relref "/projects/_index.md" >}}) links to source code, methodology, contribution records and practical security guides.
